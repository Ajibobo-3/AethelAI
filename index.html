REQUEST PATH · V1

One gateway.
Optional backup routing.

The gateway validates each API key, enforces a daily request quota, and records usage. When enabled, mapped requests can fall back from an OpenAI-compatible primary to Groq after a primary rate-limit response. This reduces reliance on one provider but cannot eliminate limits or outages; distributed GPU routing is not yet available.
